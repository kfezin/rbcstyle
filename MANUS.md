# Regras do Projeto
- Use estritamente **JavaScript moderno (ES6+)** com extensões `.js` ou `.jsx`.
- **NÃO** use TypeScript, tipos estáticos ou arquivos `.ts`/`.tsx`.
- Para animações, utilize **GSAP (com ScrollTrigger)** e **Lenis** em JavaScript puro ou dentro de componentes React/Next.js em `.jsx`.
- Mantenha a estrutura limpa e modular (ES Modules).
